## Paging rules (act first)

| # | Condition | Probe | Severity |
|---|-----------|-------|----------|
| P1 | `/health` status ∈ {`degraded`, `unhealthy`} **for >60s** | `GET /health` → `.status` | **PAGE** |
| P1 | `/health/ready` status ≠ `ready` for >60s | `GET /health/ready` → `.status` | **PAGE** |
| P2 | `checks.coordinator.crashedEngines` non-empty | `GET /health` | **PAGE** (engine dead = symbol not trading) |
| P2 | `checks.coordinator.staleEngines` non-empty while market open | `GET /health` | PAGE |
| P2 | `checks.feed.producerAlive == false` | `GET /health` | **PAGE** (feed producer thread dead) |
| P2 | `checks.feed.pollFallback == true` (the >60s age rule is applied inside the router — after 60s overall `status` degrades; age itself is **not** exposed on the endpoint) | `GET /health` | PAGE (WS→REST degraded) |
| P2 | `checks.feed.silentSymbols` non-empty **while market open** | `GET /health` | PAGE |
| P3 | `checks.journal` starts with `degraded` | `GET /health` | PAGE if >0 for >60s |
| P3 | `checks.coordinator_readiness == NOT_READY` | `GET /health/ready` | PAGE |
| P3 | `checks.coordinator_readiness == DEGRADED_NO_NEW_ENTRIES` | `GET /health/ready` | Ticket / soft page (quarantine — no new entries) |

```bash
# one-shot probes
curl -sS "$BASE/health" | jq '{status, feed: .checks.feed, coord: .checks.coordinator, journal: .checks.journal}'
curl -sS "$BASE/health/ready" | jq '{status, ready: .checks.coordinator_readiness, engine: .checks.engine}'
```

## §E4 list → concrete probes

### 1. `/health` / `/health/ready` degraded >60s — page

- `GET /health` → `status` (`ok` | `degraded` | `unhealthy`).
- `GET /health/ready` → `status` (`ready` | `not_ready`) plus
  `checks.coordinator_readiness` (`READY` | `DEGRADED_NO_NEW_ENTRIES` | `NOT_READY`).
- Alert if either is bad continuously for **60 seconds** (sample every 15–30s).

### 2. Feed block (Tasks 4–5): silentSymbols, dropCounts, pollFallback, producerAlive

Path: `GET /health` → `checks.feed`

| Field | Alert when |
|-------|------------|
| `silentSymbols[]` | non-empty **and** market open (`is_market_open()` NSE or MCX) |
| `dropCounts{}` | any key grows over a 5-min window during market hours (expect `0` in steady state; keys like `queue_full:<sym>`, `late_tick:<sym>`) |
| `pollFallback` | `true` (router degrades overall status once fallback age >60s; age not on endpoint) |
| `producerAlive` | `false` |

Feed check degrades overall `/health` status automatically — covered by P1/P2.

### 3. crashedEngines / staleEngines

Path: `GET /health` → `checks.coordinator`

| Field | Alert when |
|-------|------------|
| `crashedEngines[]` | non-empty (any) — also fails `/health/ready` (`NOT_READY`) |
| `staleEngines[]` | non-empty while market open (default threshold 300s) |
| `status` | `degraded` when either list non-empty |

### 4. journal consecutive_failures · persistence_degraded · DEGRADED_EVENT_APPEND_FAILED · bridge_write latch

| Signal | Where | Alert |
|--------|-------|-------|
| journal consecutive append failures | `GET /health` → `checks.journal` = `degraded(N)` | N > 0 for >60s |
| event-append degraded / reconciliation required | WS snapshot `risk_state.canonicalState == "DEGRADED_EVENT_APPEND_FAILED"`; engine log `⚠️ [EVENT SOURCING] … append failed` | any occurrence (blocks new entries via startup block) |
| bridge write latch (`DEGRADED_BRIDGE_WRITE` / `BRIDGE_WRITE_DEGRADED`) | `GET /health` → `checks.coordinator.integrityFlags` contains `BRIDGE_WRITE_DEGRADED` (wired via `QuantCoordinator.integrity_flags`); also `PersistenceHealth.bridge_write_degraded` process ClassVar | any occurrence — SQLite missed a row the event store has; overall status degrades |

### 5. AMT_FAILING · GATE_ERROR · DecisionDeferred

| Signal | Where | Alert |
|--------|-------|-------|
| `AMT_FAILING` | `GET /health` → `checks.coordinator.integrityFlags` contains `AMT_FAILING` (<60s window, `AMTEngine.status_flags`); log `AMT analyze failed for <sym> … (amt_failures_total=N)` | any occurrence during market hours (overall status degrades); count rising |
| `GATE_ERROR` | log `GATE_ERROR: gate N raised: …` (ERROR, fail-closed) | any occurrence |
| `DecisionDeferred` | log `DecisionDeferred reason=STALE_DTO\|DEBOUNCE\|STARTUP_BLOCK\|… symbol=…` | sustained `STALE_DTO` during market hours (decisions starved) |

`AMT_FAILING` / bridge latch are **not** on `/health` yet — use logs.

### 6. Log patterns (grep from process logs)

```text
ENGINE THREAD DIED                      # symbol stopped for the session — PAGE
[EVENT SOURCING] … append failed        # EventStore durable append failed (CRITICAL)
EMERGENCY FLATTEN                       # contingent SL-M failed — panic flatten — PAGE
emergency_halt: force-closed            # SIGTERM/emergency flatten path
INTRADAY RECONCILE: … book drift(s)     # broker-vs-engine drift, detect-only — PAGE if market open
[RECONCILIATION REQUIRED]               # broker outcome unknown — entry blocked
RECONCILIATION_REQUIRED                 # exposure status in [BLOCKED] … requires reconciliation
[BLOCKED] … startup/storage/reconciliation  # entry guard holding on unresolved persistence/recon
AMT analyze failed                      # every failure logged ERROR — count during session
GATE_ERROR: gate N raised               # gate crashed, fail-closed — ticket/any
DecisionDeferred reason=…               # STALE_DTO / DEBOUNCE / STARTUP_BLOCK / EXPOSURE_BLOCK
falling back to REST quote polling      # WS→REST poll fallback engaged
MultiplexedMarketFeed drop #N           # packet never reached an engine queue
eod_square_off: force-closed            # EOD backstop fired (expected at deadline)
DhanCircuitBreaker forced to OPEN       # broker circuit open — PAGE in market hours
WebSocket connection closed unauthenticated  # gameloop auth reject — ticket
symbol not found                        # gameloop subscription reject — ticket
```

Suggested live tail:

```bash
grep -E 'ENGINE THREAD DIED|\[EVENT SOURCING\].*append failed|EMERGENCY FLATTEN|emergency_halt: force-closed|INTRADAY RECONCILE|RECONCILIATION REQUIRED|RECONCILIATION_REQUIRED|\[BLOCKED\]|AMT analyze failed|GATE_ERROR|DecisionDeferred|falling back to REST quote polling|MultiplexedMarketFeed drop|DhanCircuitBreaker|closed unauthenticated' "$LOG"
```

### 7. Metrics canary — counters must advance in market hours

`GET /api/metrics/summary` (JSON) or `GET /api/metrics/` (Prometheus text).

| Counter | Expect (market hours) | Alert |
|---------|----------------------|-------|
| `ticks_processed` (`ticks_processed_total`) | increases every sample while feed healthy | **flat for 2 min while market open** — PAGE (dead canary) |
| `decisions_evaluated` (+ approved/blocked split) | increases on each entry evaluation | flat for 10+ min while market open — ticket |
| `trades_executed` | increases only when trades occur | **stays 0 all session while signals fire** — investigate |
| `signals_generated` | moves with approved signals | flat while decisions approve — investigate |

```bash
# canary sample twice, 60s apart
a=$(curl -sS "$BASE/api/metrics/summary" | jq '{t:.ticks_processed,d:.decisions_evaluated,x:.trades_executed}')
sleep 60
b=$(curl -sS "$BASE/api/metrics/summary" | jq '{t:.ticks_processed,d:.decisions_evaluated,x:.trades_executed}')
# PAGE if market open and b.t == a.t
```

### 8. Trade truth (§E4 items not fully instrumented as HTTP)

| Check | Probe today |
|-------|-------------|
| PositionOpened without DecisionProduced | offline: JSONL journal / EventStore export order check; live: hotpath trace |
| close without `exit_source` | logs `exit_source=` on position-manager summary lines |
| positions past EOD | EOD watchdog logs; if open positions remain after close window — PAGE |
| broker-vs-engine drift | `_intraday_reconcile` detect-and-alert every ~60s (log); no auto-action |
| per-symbol tick age | feed `silentSymbols` / coordinator `staleEngines` (proxies) |
| watchdog + producer alive | `checks.feed.producerAlive`; EOD watchdog dead-man `_on_watchdog_error` (exception path) |
| Dhan circuit states (shared + per-service) | not on `/health` — grep `DhanCircuitBreaker` (`forced to OPEN` WARNING / `reset to CLOSED` INFO) in `brokers/broker/dhan/infrastructure/resilience.py` |

## First-hour checklist (Day-1 open)

1. `GET /health` → `ok`, `feed.producerAlive=true`, `crashedEngines=[]`, `staleEngines=[]`.
2. `GET /health/ready` → `ready`, `coordinator_readiness=READY`.
3. `GET /api/metrics/summary` → snapshot `t0`; re-check +60s → `ticks_processed` advanced.
4. `dropCounts` empty / not growing; `pollFallback=false`.
5. Log tail clean of PAGE patterns above for first 15 market minutes.
6. After any restart: no `append failed`, no `ENGINE THREAD DIED`; positions restored from SQLite (see `docs/agents/domain.md` Persistence section).
