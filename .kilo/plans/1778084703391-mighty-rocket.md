## Detailed Specifications

### 1. Max Drawdown Tracker

**New file**: `app/domain/risk/service/max_drawdown_tracker.py`

**Spec**:
- Track peak equity. On each update, compute drawdown = (peak - current) / peak
- Halt trading when drawdown >= 2% (configurable, default 0.02)
- Persist state to dict for storage/restore
- Reset on new session
- Thread-safe

**Test file**: `tests/unit/domain/risk/test_max_drawdown_tracker.py`
- `test_tracks_peak_equity` — peak updates correctly
- `test_calculates_drawdown_correctly` — math is correct
- `test_halts_trading_at_max_drawdown` — halts at threshold
- `test_allows_trading_below_threshold` — doesn't halt prematurely
- `test_resets_on_new_session` — reset clears state
- `test_serializes_state` — to_dict / from_dict roundtrip
- `test_handles_zero_equity_gracefully` — no crash
- `test_update_returns_can_trade_bool` — API contract

### 2. Breakeven Engine

**New file**: `app/domain/exit/service/breakeven_engine.py`

**Spec**:
- Check if position should move to breakeven
- 1R-based BE: when unrealized_pnl >= risk_distance
- CVD-based BE: when cvd_confirms_direction AND bars_held >= 2
- Legacy 50% partial TP mode (configurable)
- Returns `BreakevenResult` frozen dataclass

**Test file**: `tests/unit/domain/exit/test_breakeven_engine.py`

- `test_does_not_move_before_1r` — LONG at 0.5R
- `test_works_for_short_positions` — SHORT at 1R
- `test_cvd_confirms_faster_be` — CVD confirms after 2 bars
- `test_cvd_requires_minimum_bars` — fails at 1 bar
- `test_legacy_50_percent_tp_still_works` — legacy mode

**Integration**: Modify `ExitEngine.evaluate()` to call BreakevenEngine before partition check.

## Test Patterns to Follow

```python
# Example test pattern from existing test suite
class TestFeature:
    @pytest.fixture
    def component(self):
        return Component(param=value)

    def test_specific_behavior(self, component):
        result = component.action(input)
        assert result.field == expected
        assert result.valid is True
```

**Conventions**:
- Use `pytest` fixtures for component setup
- Test value objects with `frozen=True` are immutable
- Test expected exceptions for invalid inputs
- Test edge cases: zero, negative, None, empty lists
- Use `pytest.approx()` for float comparisons
- Name tests: `test_<behavior>_<condition>`
