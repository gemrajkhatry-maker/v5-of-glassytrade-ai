## Technical Considerations

### Model Architecture
- LFM2.5-VL-450M is a vision-language model with 450M parameters
- Uses SigLIP2 NaFlex vision encoder (86M parameters)
- Language backbone: LFM2.5-350M
- Context window: 32,768 tokens
- Requires `AutoModelForImageTextToText` and `AutoProcessor`

### Training Approach
- Parameter-efficient fine-tuning with LoRA
- Target modules: `["q_proj", "k_proj", "v_proj", "o_proj"]` for language model
- Learning rate: 2e-4
- Batch size: 2 (due to memory constraints)
- Gradient accumulation: 4 steps
- Epochs: 3
- Use QLoRA (4-bit quantization) for efficient training

### Data Format
- ChatML format: system message + user message + assistant message
- User messages can include images (currently text-only)
- Assistant responses follow structured format: Market State, Logic, Trigger

### Hardware Requirements
- Apple Silicon Mac with MPS support
- 64GB RAM recommended for training
- CUDA GPU for faster training (if available)

## Risks and Mitigations

1. **Insufficient VRAM for training**
   - Mitigation: Use QLoRA 4-bit quantization, gradient checkpointing, small batch size

2. **Training data quality**
   - Mitigation: Use existing AMT scenarios from poc_lfm2, validate with domain experts

3. **Integration complexity**
   - Mitigation: Follow existing patterns from Gemma 4 2B integration

4. **Model performance**
   - Mitigation: Start with text-only, then gradually add vision support
