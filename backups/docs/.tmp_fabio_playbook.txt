AMT Playbook (Fabio-style) — Adapted Rules for Indian Markets (NSE F&O + MCX)
Apr 2025 base, rewritten for INR markets and our system constraints

Scope
- NSE F&O: Index options/futures (NIFTY, BANKNIFTY, FINNIFTY, MIDCPNIFTY), liquid stock options (optional)
- MCX: Commodity futures/options (CRUDEOIL, NATURALGAS, GOLDM, SILVERM, etc.)
- Execution vehicle in this system: options contracts (contract selection + position sizing in lots)

Market Hours (IST)
- NSE/BSE session: 09:15–15:30
- MCX session: 09:00–23:30
- Operational filters (recommended)
  - Skip first 5–10 minutes after open (spreads + fake moves)
  - Skip last 5–10 minutes into close for NSE; for MCX avoid thin liquidity windows (late hours vary by symbol)

Key Idea (unchanged)
Only trade when ALL 3 align:
1) Market State (Balance vs Imbalance)
2) Location (Volume Profile levels: VAH/VAL/POC and LVNs)
3) Aggression (confirmation at the level)

Important India-specific reality
- In live mode, broker executed-trade “aggressor” data may not be available; order-flow confirmation must use proxies.
- For MCX and NSE options, the cleanest auction read is usually on the underlying futures/spot; options can be noisier.

----------------------------------------------------------------------
Step 1 — Market State (India rules)
Goal: classify environment before trading.

Balance (Range / Rotation)
- Price rotates around a stable “fair value” (POC) with overlapping candles
- Most closes remain inside Value Area (previous session profile or last major balance profile)
- Breaks outside VA fail quickly and return inside

Imbalance (Trend / Search)
- Displacement away from value: range expansion + directional closes with minimal overlap
- Acceptance outside value: multiple closes beyond VAH/VAL or beyond prior balance extremes
- Pullbacks are shallow and hold above/below the reclaim leg

Practical definitions for automation (recommended thresholds)
- Use previous day session profile as baseline for NSE; for MCX use the last full “session block” profile
- “Displacement leg” = last impulse with:
  - 3+ consecutive candles in one direction AND
  - total leg range >= 1.5x the last N-candle average range AND
  - closes near extremes (trend efficiency)
- “Acceptance” = 2+ closes beyond VAH/VAL (or beyond balance high/low) with rising volume and/or rising OI

When NOT to trade
- If market state is unclear (mixed overlap + no acceptance): stay flat
- If volatility spikes but spreads widen (common in MCX): wait for spread normalization

----------------------------------------------------------------------
Step 2 — Location (Volume Profile rules)
Goal: decide where price should react (don’t trade mid-air).

Profile inputs (recommended)
- NSE index trading: prefer underlying (index futures or index proxy) profile for state/location
- Options execution: use option profile only for fine-tuning entries/exits (because options are strike-specific)
- MCX: prefer underlying futures profile for state/location; use option profile for execution

Levels to mark
- POC: the “magnet” for mean reversion and the first target for trend continuation into balance
- VAH/VAL: balance boundaries
- LVNs inside the impulse leg:
  - Build a profile on the impulse leg that broke structure
  - LVNs inside that leg are “reaction zones” on retrace

India-specific LVN usage
- NSE weekly expiries: use more conservative LVNs near ATM because gamma effects can exaggerate moves
- MCX: use LVNs with bigger buffer (tick-value + slippage are higher); prefer trades near high-liquidity hours

Do
- Place alerts before LVNs; do not place blind limits
- Use a small buffer around LVN boundaries (instrument tick-size and spread dependent)

----------------------------------------------------------------------
Step 3 — Aggression / Confirmation (India rules)
Goal: enter only when the level “responds”.

If true executed-trade aggression is available
- Require aggressive prints in trend direction at LVN (trend model) or at reclaim (mean reversion model)

If only proxies are available (common)
Use a “confirmation bundle” (require at least 2/3):
1) Liquidity/Spread: spread % tight enough for the market (NSE tighter than MCX)
2) Volume impulse: sudden volume increase vs recent average (option + underlying if available)
3) Pressure proxy: rising OI change and/or sustained bid/ask imbalance signal (if provided by broker quote)

No confirmation = no trade

----------------------------------------------------------------------
Setup 1 — Trend Continuation (Out-of-Balance → Seek New Balance)
Trigger sequence
1) Market is out of balance (displacement + acceptance)
2) Identify impulse leg that broke structure
3) Profile the impulse leg and mark LVNs inside it
4) Wait for pullback into LVN (avoid first touch if the move is too sharp)
5) Enter only on confirmation at the LVN in direction of trend

Stop Loss (India)
- Place SL just beyond the confirming “aggressive” area / rejection swing
- Add a small buffer based on:
  - NSE index options: 1–2 ticks
  - MCX: 1–2 ticks minimum, but also respect typical spread and slippage

Break-even rule
- If confirmation remains strong after entry (pressure stays), move to break-even earlier than normal
- If confirmation disappears quickly (no follow-through), scratch/exit early

Target rule
- Primary target = previous balance POC
- Exit full position at POC by default
- Only allow a runner/trail if:
  - the day remains strongly trending AND
  - pullbacks stay shallow AND
  - spreads remain tight

----------------------------------------------------------------------
Setup 2 — Mean Reversion (Failed Breakout → Back Into Balance)
Trigger sequence
1) Market must be in balance (or prior-day balance reference is clean)
2) Price breaks out of balance but fails to hold (no acceptance)
3) Wait for a clear reclaim back inside balance
4) Wait for pullback into reclaim leg LVN
5) Enter only on confirmation in the snap-back direction

Invalidation rule
- If wrong, it should be wrong immediately
- Never widen SL

Target rule
- Target = balance POC (center of value), exit full position there

----------------------------------------------------------------------
Risk Management (India)
Risk sizing
- Risk per trade: 0.25% to 0.5% of account
- Position sizing must be in lots (options trade in lot-size multiples)
- If calculated size is huge, cap by notional and liquidity limits

Operational risk filters
- Skip trades with poor liquidity (low volume/OI) or wide spreads
- Avoid holding into illiquid time windows (especially MCX late hours)

System Implementation Notes (rules to improve the current system)
Market State
- Add a strict “acceptance outside value” gate (close count beyond VA) for trend-continuation entries
- For NSE: prefer computing state from index futures/spot rather than option candle stream

Location
- Compute LVNs/POC from the impulse leg on the underlying, then map “location zones” to option strikes
- For options, treat LVNs as zones (not exact prices) because option Greeks distort microstructure

Aggression
- In live mode, treat “aggression” as a proxy bundle (spread + volume impulse + OI change)
- In paper mode, use the synthetic aggressor only as a training/validation aid, not as a live requirement

Risk/Stops/Targets
- Keep the default target-at-POC behavior
- Only trail on rare strong-trend days with continued displacement confirmation
