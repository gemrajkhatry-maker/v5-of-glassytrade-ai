Executive Summary
The Valentini Scalper is a professional-grade order flow trading
system implementing Fabio Valentini's Triple-A methodology
(Absorption → Accumulation → Aggression) for cryptocurrency
scalping. This document provides complete technical specifications,
architecture details, and step-by-step replication instructions for
deploying a production-ready automated trading platform.
Technology Stack: Node.js/TypeScript backend, React frontend,
SQLite database, Binance market data integration, FastAPI Python
engine (optional)
Key Features: Real-time range bar charting, volume profile analysis,
VWAP bands, absorption detection, Triple-A state machine, paper
trading OMS, live SSE streaming, configurable risk management

2. Core Components Deep Dive
2.1 Range Bar Generator
Purpose: Convert time-based candlesticks (1-minute klines) into
range bars with fixed price movement.
Algorithm:

Range bars close when price movement reaches a threshold (e.g., 50
points), regardless of time. This filters out time-based noise and
focuses on price action.
Implementation Logic:

  1. Calculate auto range size using ATR(14) if not specified
  2. Simulate tick-by-tick price movement within each 1m candle
  3. Track current bar's open, high, low, close, volume
  4. When range threshold reached (high - low >= rangeSize), close
     bar
  5. Distribute volume proportionally across generated bars
Key Function: buildRangeBars(klines, rangeSize)

Input: Array of 1-minute Binance klines
Output: Array of range bars with isComplete flag

Auto Range Calculation:
Code Location: server/range-bar-generator.ts

Edge Cases Handled:

     Incomplete bars (marked with isComplete: false)
     Zero volume periods (proportional distribution)
     Gap movements (tick simulation ensures continuity)

2.2 Volume Profile Construction
Purpose: Build horizontal volume distribution to identify high-
activity price levels (POC, VAH, VAL).
Algorithm:

  1. Determine price range:
  2. Divide into buckets with width = range size
  3. For each bar, allocate buy/sell volume to corresponding bucket
  4. Calculate Point of Control (POC) = bucket with max total volume
  5. Calculate Value Area (68% volume around POC) using expansion
     algorithm
  6. Derive VAH (Value Area High) and VAL (Value Area Low)
Value Area Expansion:

Starting from POC, iteratively expand to adjacent buckets (higher or
lower volume first) until 68% of total volume captured.
Data Structure:

interface VPLevel {
price: number;
buyVol: number;
sellVol: number;
total: number; // buyVol + sellVol
delta: number; // buyVol - sellVol
}
interface VolumeProfile {

vah: number; // Value Area High
val: number; // Value Area Low
step: number; // Bucket size
}
Code Location: server/strategy-engine.ts → buildVP()

Use Case: POC acts as magnet for price, VAH/VAL define trading
ranges for mean-reversion setups.

3.3 Database Persistence Flow
Trade Lifecycle:

  1. Signal Generated: Strategy engine produces LONG/SHORT
     signal
  2. Create Trade: INSERT into trades table
        • symbol, side, entryPrice, stopLoss, takeProfit
        • quantity (calculated from risk per trade)
        • status = "open"

  3. Monitor Position: On each bar update, check exit conditions
        • Price hits stop-loss → close with loss

     closedAt
  5. Display History: Query trades via GET /api/trades

4. Trading Strategy Implementation
4.1 Valentini Triple-A Methodology
Philosophy: Institutional order flow creates predictable patterns
before directional moves. Triple-A captures this footprint.
Phase 1: Absorption

What: Large volume with minimal price movement
Where: Support (for longs) or resistance (for shorts)
Why: Institutions absorbing supply/demand before accumulation

Detection:

     Volume           average
     Price range         rangeSize
     Side: BUY if buyVol      , else SELL
Phase 2: Accumulation
What: Price consolidates near Point of Control (POC)
Where: Within 2 range steps of POC
Why: Institutions building position at value

Validation:

    2+ bars elapsed since absorption
    Price
Phase 3: Aggression (Signal)

What: Price breaks above/below VWAP with absorption confirmation
Where: VWAP breakout zone
Why: Institutions pushing price directionally

Entry Conditions (LONG):

    BUY absorption detected
    Price VWAP
    R:R 1.5
Entry Conditions (SHORT):

    SELL absorption detected
    Price VWAP
    R:R 1.5
Stop-Loss Placement:

    LONG: Below VAL - 1 step
    SHORT: Above VAH + 1 step
Take-Profit Calculation:

    TP = Entry    (Entry - SL)   tpMultiplier (default 2.0)

4.2 Complementary Setups
Value Area Fade (Mean-Reversion)

LONG Setup:

    Price near VAL
    Price above VWAP
    Cumulative delta positive
    Target: POC
SHORT Setup:

    Price near VAH
    Price below VWAP
    Cumulative delta negative
    Target: POC
ORB Breakout (Opening Range Breakout)

    First 6 range bars define ORB high/low
    Breakout above ORB high + volume confirmation → LONG
    Breakdown below ORB low + volume confirmation → SHORT

8.1 Adding New Indicators
Example: RSI (Relative Strength Index)

Step 1: Add calculation function to strategy-engine.ts:

private calcRSI(bars: RangeBar[], period = 14): number {
if (bars.length < period + 1) return 50;
let gains = 0, losses = 0;
for (let i = bars.length - period; i < bars.length; i++) {
const change = bars[i].close - bars[i - 1].close;
if (change > 0) gains += change;
else losses -= change;
}
const avgGain = gains / period;
const avgLoss = losses / period;
const rs = avgGain / avgLoss;
return 100 - (100 / (1 + rs));
}
Step 2: Integrate into analysis result:

const rsi = this.calcRSI(bars);
return { ...result, rsi };
Step 3: Display in frontend (e.g., KPI bar or new panel).
