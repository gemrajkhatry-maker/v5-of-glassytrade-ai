# GlassyTrade AI (v5) - Technology Stack

## Frontend
- **Framework:** React 19 (Functional Components, Hooks)
- **Language:** TypeScript (Strict Mode)
- **Build Tool:** Vite
- **Styling:** Tailwind CSS (Glassmorphism theme)
- **Visualization:** Lightweight Charts (2D Canvas-based)
- **Icons:** Lucide-React
- **Utilities:** UUID (ID generation)
- **Testing:** Vitest, React Testing Library

## Backend
- **Framework:** FastAPI
- **Language:** Python 3.11+
- **Asynchronous Runner:** Uvicorn
- **Validation:** Pydantic
- **HTTP Client:** HTTPX
- **WebSocket:** websockets library
- **Persistence:** SQLite (via StoragePort)
- **Testing:** Pytest, Pytest-Asyncio

## AI / Machine Learning
- **Inference Engine:** MLX (Apple Silicon optimized)
- **Models:** Nanbeige 3B, Qwen (LLMs), MaskablePPO (Reinforcement Learning)
- **Probability:** LightGBM
- **Frameworks:** PyTorch, Transformers, PEFT (LoRA)

## External Services & Infrastructure
- **Broker Integration:** Dhan API, Binance (REST/WS)
- **LLM Gateway:** OpenRouter
- **Platform:** macOS (Apple Silicon optimized)
